# Idea Spinner

A classroom warm-up for physical computing. Press the big red **Mix!** button and four cards land on an **Input** (a sensor), a **Process** (the device doing the computing: micro:bit, Pico or Raspberry Pi), an **Output** and a **Material** to build with. Learners then pitch a project that uses all four.

A fresh take on [idea_mixer](https://github.com/jrobinson-uk/idea_mixer) (2016), rebuilt to run in any browser.

There's also a [BBC micro:bit version](microbit/) (`/microbit/`) with three cards that use only what's built into the micro:bit. See [microbit/README.md](microbit/README.md).

## Using it in a lesson

- Open the page on the projector and press **Mix!**, or press **Space**.
- **Lock** a card with its padlock to keep it, then mix again to change only the others. For example, lock *micro:bit* on the Process card so every idea uses one.
- The **cog** opens settings:
  - **Include AI ingredients** (off by default) adds an *AI classifier* input and a *generative AI* output.
  - **Sound effects** (off by default).
  - A list of every ingredient, for planning or as a key.

Settings are remembered in your browser. Nothing is sent anywhere.

## Adding or changing ingredients

1. Add a line to [`data/ingredients.json`](data/ingredients.json):

   ```json
   { "id": "heart-rate", "name": "Heart rate sensor", "wheel": "input", "hint": "Senses your pulse", "tags": [] }
   ```

   - `wheel` is `input`, `process`, `output` or `materials`.
   - `tags: ["ai"]` puts the item behind the AI toggle. The toggles themselves are the `options` list at the top of the file.
   - Optional: `image` points to a picture somewhere else, and `layers` stacks several pictures on top of each other (the micro:bit site uses this).

2. Add an illustration at `img/ingredients/<id>.svg`. The page finds it from the `id`.

The cards themselves come from the `wheels` list at the top of the same file, so you can add, remove or reorder a card there. Each card's colour is set in `css/styles.css` under `[data-wheel="…"]`.

The illustrations are generated by [`tools/make_svgs.py`](tools/make_svgs.py), which keeps them in one house style: a 240×240 canvas, a white rounded backdrop, 6px dark outlines and flat fills. To add one, add an entry to the `art` dictionary and run:

```bash
python3 tools/make_svgs.py img/ingredients
```

`tools/contact_sheet.py` builds an SVG sheet of every illustration so you can review them side by side.

## Running it locally

It's plain HTML, CSS and JavaScript with no build step. It does need a local server, because browsers block loading the data file from `file://`:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> (or <http://localhost:8000/microbit/>). The logic tests run at <http://localhost:8000/tests/picker.test.html>, and with `?deck=microbit` for the micro:bit deck.

## How it works

| File | Job |
|---|---|
| `js/picker.js` | Picks a combination. Locked cards stay put, unlocked cards always change, there are no duplicates, and AI items are filtered by the toggle. No DOM, so it's easy to test. |
| `js/reel.js` | Animates one card's strip to its target, or cross-fades when "reduce motion" is on. |
| `js/main.js` | Wires up the button, keyboard, locks, settings and screen-reader announcements. |
| `js/settings.js` | Saves settings to `localStorage` safely. |
